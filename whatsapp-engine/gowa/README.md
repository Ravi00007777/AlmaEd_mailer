# gowa goes here

Download **gowa v9.5.0** for your laptop from
https://github.com/aldinokemal/go-whatsapp-web-multidevice/releases/tag/v9.5.0, unzip it, and put the program file in this folder:

| Laptop | Zip to download | File to put here |
| --- | --- | --- |
| Windows | `whatsapp_9.5.0_windows_amd64.zip` | `windows-amd64.exe` |
| Mac (Apple chip) | `whatsapp_9.5.0_darwin_arm64.zip` | `darwin-arm64` |
| Mac (Intel) | `whatsapp_9.5.0_darwin_amd64.zip` | `darwin-amd64` |

The engine finds it here and starts it automatically. gowa is open source (MIT licence) by Aldino Kemal.
It isn't committed to this repo because it's a large program file, and gowa keeps your WhatsApp login (`storages/`) in this folder too.
